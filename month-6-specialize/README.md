# Month 6 — Specialize, Publish, Apply

**Goal:** consolidate into a portfolio and start interviewing (or negotiating an internal pivot).

## Pick a direction

Choose ONE based on what you enjoyed most:

### A. AI Application Engineer
Product-facing AI features, RAG, agents, evals. Broadest demand.
- [ ] Contribute to an open-source AI project (LangChain, LlamaIndex, Langfuse, promptfoo, etc.) — one real PR merged
- [ ] Polish month-2 RAG project as portfolio centerpiece

### B. AI Platform / Infra
Inference serving, gateways, data pipelines. Less crowded, pays well.
- [ ] Deploy a model with [vLLM](https://github.com/vllm-project/vllm) or [TGI](https://github.com/huggingface/text-generation-inference)
- [ ] Skim [Chip Huyen — Designing ML Systems](https://www.oreilly.com/library/view/designing-machine-learning/9781098107956/) for data-side concepts
- [ ] Build a small model gateway / router as a portfolio piece

### C. Senior Backend + AI
Stay a backend engineer but become the AI-literate one on the team. Valid if you don't want to reinvent.
- [ ] Pitch and ship one AI feature inside your current Laravel codebase
- [ ] Write it up internally and externally

## Portfolio checklist

- [ ] 2–3 real projects on GitHub with thorough READMEs
- [ ] Each README shows: what it does, stack, eval results, tradeoffs, what you'd do differently
- [ ] 2+ blog posts explaining decisions (not tutorials — decisions)
- [ ] Updated LinkedIn with AI project summaries
- [ ] Resume rewritten with AI work above Laravel work

## Apply

- [ ] Shortlist 20 target companies
- [ ] Reach out to 5 people at those companies for informal chats
- [ ] Apply to 10 roles
- [ ] Do one mock interview focused on AI system design

## The money question

When negotiating: "AI-literate backend engineer with 7 yrs production experience and a portfolio of shipped AI systems" is a far stronger position than "Laravel developer." Price accordingly.
